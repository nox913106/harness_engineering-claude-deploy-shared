# PROJECT_INIT.md — 專案啟動強制檢查清單

> 版本：v0.1
> 最後更新：2026-06-05
> AI 不得修改本文件

---

## 強制執行聲明

任何專案在第一行程式碼之前必須完成本文件所有階段。
階段不可跳過、不可倒序。
每個階段有明確完成標準，未通過不得進入下一階段。

---

## 階段一：功能清單明確

每個功能必須回答以下三個問題，回答不出來的功能不得列入開發清單：

```
□ 這個功能是給誰用的？
□ 這個功能做完的樣子是什麼？（驗收條件）
□ 這個功能是 MVP 必須有、還是之後再說？
```

凍結規則：進入階段二後，功能清單不可新增項目。

✅ 完成標準：所有功能均已回答三個問題，清單已凍結，負責人簽核。

---

## 階段二：架構定義

強制產出四份文件（缺一不可）：

```
□ docs/SPEC.md    — 系統規範、目錄結構、資料流
□ docs/GUARD.md   — 安全邊界、AI 不可逾越的操作清單
□ docs/ROLES.md   — AI 角色定義、職責邊界、AI Leader
□ docs/STATE.md   — 當前狀態、已知問題、下一步
```

強制建立目錄結構（參考 SYSTEM_STANDARD.md 第一節）。

✅ 完成標準：四份文件完成初版，目錄結構建立，git repo 初始化。

---

## 階段三：記錄機制啟動

```
□ Log 格式已確認（參考 SYSTEM_STANDARD.md 第二節）
□ docs/ERROR_CODE.md 建立（本專案的 error code 清單）
□ git repo 初始化，.gitignore 包含 .env、logs/、__pycache__/
□ logs/DEBUG_LOG.md 建立（空的也算）
□ commit message 格式確認：[type] 描述
```

✅ 完成標準：log 格式定義，ERROR_CODE.md 建立，git 初始化。

---

## 階段四：機敏資訊保護

```
□ config/.env.example 建立（含所有變數名稱，值留空）
□ .env 加入 .gitignore
□ docs/GUARD.md 已明確列出 AI 不可讀取的檔案清單
□ 程式碼中禁止硬編碼任何憑證、IP、密碼
□ config/settings.yaml 只存非機敏設定
```

✅ 完成標準：.env.example 建立，GUARD.md 已列機敏保護清單。

---

## 階段五：DB 選擇

```
□ 資料庫選型已確定
□ 選型理由記錄於 SPEC.md（必須說明為什麼）
□ ORM 或查詢框架選型已確定
□ 資料 schema 初版已定義
□ 備份策略已定義
```

✅ 完成標準：選型理由已寫入 SPEC.md，schema 初版完成。

---

## 階段六：登入安全

```
□ 認證機制選型已確定（JWT / Session / OAuth / API Key / 無需認證）
□ 選型理由記錄於 SPEC.md
□ Token / session 有效期已定義
□ 權限層級已定義
□ 生產環境 /docs（Swagger UI）必須關閉或加上認證保護
□ 開發與生產環境認證設定必須分離
□ 失敗登入次數限制已定義
```

✅ 完成標準：認證機制選定，/docs 保護規則確認。

---

## 階段七：前端類型定義

專案啟動時必須選定前端類型（擇一）：

```
□ 類型一：純 CLI
    → 定義指令介面與參數規範即可

□ 類型二：API + Swagger UI（FastAPI）
    → 定義 endpoint 命名規範
    → 生產環境 /docs 必須關閉

□ 類型三：Web GUI
    → 完成 SYSTEM_STANDARD.md 第七節 System 基本條件
    → 在 SPEC.md 填寫 Project 專屬條件

□ 類型四：報告輸出型（HTML 模板）
    → 模板變數名稱清單記錄於 SPEC.md
    → 模板視為受保護檔案，AI 只能提建議不能直接修改
```

System 基本條件（類型三強制）：

```
□ 響應式設計（RWD）基本支援
□ 無障礙基本規範（alt text、對比度最低標準）
□ 跨瀏覽器基本相容（Chrome / Firefox 最新兩版）
□ 載入效能基本要求（首屏 3 秒內）
□ 語系支援順序：英文 > 繁體中文 > 簡體中文
□ 使用者語系選擇記憶於 Cookie，跨 session 保留
□ 所有語系套件與字型資源必須落地，不依賴外部 CDN
□ AI 不可直接修改已凍結的模板或元件檔案
```

Project 專屬條件（填寫於 SPEC.md）：

```
□ 設計語言來源
□ 色彩規範（主色、輔色、警示色）
□ 字型選擇
□ 元件庫選擇
□ 受保護元件清單
□ 動畫與互動效果邊界定義
```

✅ 完成標準：前端類型選定，對應規範完成。
